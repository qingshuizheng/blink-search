* blink-search 重构计划（分支 =refactor/full=）

基线：上游 =957191b=（2026-10-17）。允许破坏兼容，**不做兼容 shim**（Elisp 与
Python 两侧同属本仓库，一起改；对外只有 Emacs 侧的公开命令与选项保持同名）。
本文件是路线图 + 验收标准；每个阶段对应一个（或一组）可 review 的提交。

** 目标

1. **docstring 完整**：所有 =defun=/=defmacro=/=defsubst=/=defvar=/=defconst=/
   =defcustom=/=defface=、以及 Python 的 function/class 都有 docstring，并且是
   "能读"的：首行是完整句子（以句号结尾）、参数在正文里被提到、不超过 80 列。
2. **结构性重构**：见「目标结构」；重点是 Elisp 与 Python 的协议单一来源、
   Python 侧的 backend 注册与搜索/渲染状态分离、把两个 god file
   （=blink-search.el= 1104 行、=blink_search.py= 516 行）拆开。
3. **可验证**：每个阶段都有机器判据（见「验收」），并且有本地测试兜底。

** 目标结构

*** Elisp

| 文件 | 职责 |
|------+------|
| =blink-search.el= | 门面：=blink-search= / =blink-search-quit= / =blink-search-restart-process= / =blink-search-kill-process= / =blink-search-start-process=，=require= 其余模块并 =provide= |
| =blink-search-protocol.el= | 协议单一来源：=blink-search-protocol-version=、EPC 方法名与参数形状、两侧共用的 =custom= 名称表 |
| =blink-search-state.el= | 四个内部 buffer 与界面状态（candidate/backend 选中项、计数、posframe frame），状态 **只在这里 defvar** |
| =blink-search-process.el= | EPC 服务端/客户端、Python 进程生命周期、=eval-in-emacs= / =get-emacs-var= 回调 |
| =blink-search-input.el= | =blink-search-mode= 与 keymap、输入监听（=#= / =!= / =;= / =:= 前缀） |
| =blink-search-ui.el= | 窗口布局（bottom / posframe）、缓冲区别名选项、图标与主题颜色 |
| =blink-search-render.el= | candidate/backend/tooltip 三个 buffer 的绘制，纯函数尽量可单测 |
| =blink-search-navigate.el= | 上下选择、分组跳转、quick-do、action 分发、=goto-column= |
| =backend/blink-search-*.el= | 各 Elisp backend 的候选产生器（只依赖 process + state） |

*** Python

| 文件 | 职责 |
|------+------|
| =blink_search.py= | 入口：组装并启动 EPC server / 事件循环，然后 =join= |
| =core/protocol.py= | =PROTOCOL_VERSION=、EPC 方法名与消息字段常量 |
| =core/backend.py= | =SearchBackend= 基类 + 注册表（=register_backend= / =backend_by_name=） |
| =core/registry.py= | backend 发现：把 =backend/*.py= 的类实例化并注册 |
| =core/search.py= | 搜索执行：ticker、线程、子进程（与上游同名同职责） |
| =core/session.py= | 一次 blink-search 会话的状态机：候选表、backend 表、渲染窗口、选择 |
| =core/navigator.py= | 默认 backend 列表、=PDF= 条件插入、目录初始化、历史记录 |
| =core/utils.py= | EPC 小工具（与上游同职责，清掉死代码与裸 except） |
| =backend/search_*.py= | 每个 backend 一个类，继承 =SearchBackend=，自带 =NAME= 并注册 |
